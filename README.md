# Приложение «Планировщик задач»

Клиент-серверное Android-приложение на Kotlin. Курсовая работа по дисциплине
«Разработка клиент-серверных мобильных приложений».

## Стек

- **Клиент:** Kotlin, Jetpack Compose (Material 3), MVVM (ViewModel + StateFlow),
  Retrofit 2 + kotlinx-serialization, Navigation Compose, DataStore Preferences, Coroutines.
- **Сервер:** Ktor 2.3.12 + Exposed 0.53 + SQLite, JWT (java-jwt), BCrypt (jBCrypt).

## Структура

- `ktor-server/` — серверная часть (REST API, база данных).
- `app/` — Android-приложение.

## Тестовые учётные записи

Создаются автоматически при первом запуске сервера:

- `admin` / `admin123` — роль ADMIN
- `user` / `user123` — роль USER

При первом старте сервер создаёт файл базы данных `taskplanner.db` и заполняет её
6 категориями, 14 задачами и записями журнала изменения статусов. Чтобы пересоздать
данные, удалите файл `ktor-server/taskplanner.db` и перезапустите сервер.

## Запуск сервера

Из корня проекта:

```
gradlew :ktor-server:run
```

(в macOS и Linux — `./gradlew :ktor-server:run`)

Сервер поднимается на `http://0.0.0.0:8080`. Проверить работу можно так:

```
curl -X POST http://localhost:8080/auth/login -H "Content-Type: application/json" -d "{\"login\":\"user\",\"password\":\"user123\"}"
```

## Запуск Android-приложения

1. Откройте каталог `task-planner` в Android Studio и дождитесь синхронизации Gradle.
   Файл `local.properties` с путём к Android SDK будет создан автоматически.
2. Запустите серверную часть (см. выше) — сервер должен работать **до** входа в приложение.
3. Запустите конфигурацию `app` на **эмуляторе** Android.
   На физическом устройстве адрес `10.0.2.2` работать не будет: это специальный адрес,
   по которому именно эмулятор обращается к localhost компьютера. Для запуска на телефоне
   замените `BASE_URL` в `RetrofitClient.kt` на IP-адрес компьютера в локальной сети
   и добавьте этот адрес в `app/src/main/res/xml/network_security_config.xml`.
4. Войдите под учётной записью `user/user123` или `admin/admin123`.

Базовый адрес сервера задан константой в
`app/src/main/kotlin/com/example/taskplanner/data/api/RetrofitClient.kt`:

```kotlin
const val BASE_URL = "http://10.0.2.2:8080/"
```

## Эндпоинты сервера

| Метод | Путь | Доступ |
|---|---|---|
| POST | `/auth/register` | без авторизации |
| POST | `/auth/login` | без авторизации |
| GET | `/tasks` (`?query=&category=&status=&priority=`) | авторизованные |
| GET | `/tasks/{id}` | владелец или ADMIN |
| POST | `/tasks` | авторизованные |
| PUT | `/tasks/{id}` | владелец или ADMIN |
| PATCH | `/tasks/{id}/status` | владелец или ADMIN |
| DELETE | `/tasks/{id}` | владелец или ADMIN |
| GET | `/tasks/{id}/history` | владелец или ADMIN |
| GET | `/all-tasks` | только ADMIN |
| GET | `/stats` | авторизованные |
| GET | `/admin/stats` | только ADMIN |
| GET | `/categories` | авторизованные |
| POST | `/categories` | только ADMIN |
| PUT | `/categories/{id}` | только ADMIN |
| DELETE | `/categories/{id}` | только ADMIN |

## Реализованная функциональность

- Регистрация и авторизация с выбором роли, JWT-токен со сроком действия 24 часа.
- Список задач с названием, описанием, категорией, приоритетом, статусом и сроком.
- Создание, редактирование, удаление задач, быстрая смена статуса.
- Журнал изменения статусов задачи.
- Выделение просроченных задач.
- Поиск с задержкой debounce 500 мс, кнопка «Очистить», история поиска до 10 запросов.
- Фильтрация по категориям и статусам, плейсхолдеры пустого результата и ошибки.
- Личная статистика пользователя и общая статистика администратора.
- Панель администратора: все задачи пользователей, справочник категорий, статистика.
- Профиль пользователя и выход из аккаунта.
- Тёмная тема с сохранением выбора в DataStore.
- Сохранение поискового запроса при повороте экрана (SavedStateHandle).
- Обработка сетевых ошибок: приложение не падает при недоступном сервере.
